# Сервіс оракула — заплановано для ЛР №2–4

Python і web3.py. Сервіс читатиме завершені результати плану з PostgreSQL,
формуватиме звіт поза ланцюгом, обчислюватиме SHA-256 його точних байтів та
публікуватиме хеш і посилання через CacheAuditRegistry від адреси з ORACLE_ROLE.
Потрібно зберігати txHash і розрізняти очікування, успішну квитанцію та помилку.
Реалізацію ще не додано.
