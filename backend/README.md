# Серверна частина — заплановано для ЛР №2–4

FastAPI: автентифікація через підпис гаманця, завантаження зображень, перевірка дозволів,
AES-256-GCM, доступ до Kubo й резервного сховища, журнал у PostgreSQL та RAM-кеш.
Передбачено один процес API. Сервер і його залежності ще потрібно реалізувати та перевірити.
