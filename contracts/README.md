# Смартконтракти — заплановано для ЛР №2–4

- ImageRegistry: CID зашифрованого об'єкта, SHA-256 оригіналу, власник.
- AccessPayment: умови продажу, дозволи, придбання доступу та виведення коштів.
- CacheAuditRegistry: версія моделі, період, хеш і посилання на звіт оракула.

Плануються Solidity, OpenZeppelin і локальна Hardhat Network.
Вихідний код, тести та конфігурацію Hardhat буде додано під час реалізації.
