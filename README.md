# Гібридне сховище зображень із прогнозом звернень

Навчальний проєкт з дисципліни «Технологія блокчейн та машинне навчання».
Команда: Данченко Д. О., Пархоменко О. А., група ПЗПІ-23-9.

Зображення зберігатимуться зашифрованими в IPFS і резервному файловому сховищі.
Ethereum використовуватиметься для реєстрації метаданих, прав доступу, оплат та аудиту кешування.
Random Forest і LightGBM прогнозуватимуть добовий попит для попереднього заповнення RAM-кешу.

## Поточний стан

Підготовлено генератор, синтетичний набір даних, ноутбук первинного аналізу та вісім графіків.
Обчислено базовий прогноз «буде як учора» на VALIDATION.
Реалізація API, трьох контрактів, браузерного інтерфейсу, оракула та прогнозного кешу запланована для ЛР №2–4.
Наявність каталогів цих компонентів не означає, що вони вже реалізовані.

## Структура

| Шлях | Призначення |
|---|---|
| `generate_data.py`, `config.json` | Генерація і перевірка синтетичного набору |

## Запуск аналізу у Windows

Відкрийте PowerShell у кореневому каталозі цього проєкту, де лежить `analysis.ipynb`.
Команди нижче використовують окреме віртуальне середовище та не потребують зміни політики виконання PowerShell.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-eda.txt
.\.venv\Scripts\python.exe generate_data.py --check
.\.venv\Scripts\python.exe -m notebook
```

У браузері відкрийте `analysis.ipynb`, виконайте всі клітинки згори вниз і збережіть ноутбук.
Генератор потребує Python 3.10 або новішого. Якщо команда `py` відсутня, для створення середовища використайте `python -m venv .venv`.

## Запуск аналізу у Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-eda.txt
.venv/bin/python generate_data.py --check
.venv/bin/python -m notebook
```

Готові CSV вже включено. Ноутбук оновлює лише `analysis_output/` і не змінює вихідні дані.
Для нового незалежного запуску генератора можна використати `python generate_data.py --output-dir data_local`.
Звичайний запуск `python generate_data.py` перезаписує каталог `data`.

## Набір даних і перевірка результатів

- 100 000 успішних користувацьких звернень, 1 000 ідентифікаторів зображень, 84 доби.
- Період: 10.08.2026–01.11.2026, UTC; seed = 42.
- Вхідні ознаки: `lag1`, `lag2`, `lag7`, `mean7`, `weekday`; ціль: `target_count`.
- Хронологічний поділ за спільними датами: 7 діб WARMUP, 49 TRAIN, 14 VALIDATION, 14 TEST.
- Основний аналіз виконано на TRAIN. MAE базового прогнозу на VALIDATION: 0,8305.
- Якість на TEST та ефективність кешування ще не оцінювалися.

CSV у комплекті збігаються за SHA-256 з файлами, використаними у наданих результатах аналізу.
`analysis_output/analysis_summary.json` зберігає версії середовища початкового аналізу;
позначення умов поширення в цьому файлі оновлено окремо від числових результатів.
Після власного запуску збережіть фактичні залежності командою
`.\.venv\Scripts\python.exe -m pip freeze > requirements-eda.lock.txt`.
Файл `requirements-eda.txt` містить діапазони сумісних версій, а не повний зафіксований знімок середовища.

## Конфігурація майбутніх сервісів

Для реалізації ЛР №2–4 скопіюйте `.env.example` у `.env` і заповніть локальні значення.
Наведені змінні є узгодженим прикладом конфігурації; генератор і ноутбук їх не використовують.
Адреси контрактів заповнюються після локального розгортання.
Поточний комплект не містить команд запуску ще не реалізованих API, контрактів або інтерфейсу.

## Умови поширення даних

Синтетичні CSV у `data/raw/` та `data/processed/` позначено CC0 1.0 Universal (CC0-1.0).
Зовнішні журнали, персональні дані та сторонні зображення не використовуються.
Повний текст наведено у `data/LICENSE`: https://creativecommons.org/publicdomain/zero/1.0/.
Це позначення стосується CSV; ліцензію для програмного коду й документації ним не встановлено.
