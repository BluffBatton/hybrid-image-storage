# Моделі та прогнозування — заплановано для ЛР №2–4

Random Forest і LightGBM використовуватимуть однакові ознаки:
lag1, lag2, lag7, mean7, weekday. Ідентифікатор зображення є ключем для зв'язування.
Поділ даних — за часом; вибір моделі й параметрів — за MAE на VALIDATION.
Після фіксації параметрів TEST використовується для підсумкового порівняння.

Готовий первинний аналіз міститься в кореневому analysis.ipynb.
Код навчання, збереження моделей і формування плану кешування ще потрібно реалізувати.
